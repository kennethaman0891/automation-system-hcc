Application Architecture Overview

The HCC system follows a layered architecture:

🔒 Security Layer
.htaccess files block HTTP access to sensitive dirs & file types. auth_check.php enforces RBAC on all admin pages. CSP, HSTS, X-Frame-Options headers sent everywhere.
🖥️ Client Layer
5 CSS files + 15 JS modules power the admin dashboard, entry forms, report card PDF export, and WhatsApp share hub. Logo embedded as base64 for offline PDF generation.
⚙️ Business Engine
functions.php (110KB) is the monolithic core: DB access, auth, Excel parsing (PhpSpreadsheet), report card logic, HMAC token verification.
🌐 Integration Layer
4 AJAX API endpoints serve dynamic data. Puppeteer automation sends PDFs via WhatsApp Web. Public pages use HMAC-signed URLs for parent verification.
🗄️ Data Layer
MariaDB database hcc_admin with tables: report_card (7,856 rows), unit_test_results (8,418 rows), student_promotion_history (1,206 rows), class_subjects (161 rows).
📄 Entry Points
Admin: admin/login.php → dashboard.php Public: public_card.php, public_slip.php, public_bonafide.php (all HMAC-verified)
